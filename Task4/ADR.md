### <a name="_qmphm5d6rvi3">**Решение**</a>

#### **Обновлённая архитектура передачи данных о ставках**

Для внутреннего колл-центра:

- Реализован Real-time API между АБС и системой колл-центра
- Данные обновляются при изменении ставок с задержкой ≤5 минут
- Кэширование на стороне колл-центра для снижения нагрузки

Для партнёрского колл-центра:

- Автоматическая генерация XLS-файлов в АБС 2 раза в день (08:00 и 20:00)
- Передача через SFTP на защищённый файловый сервер банка
- Автоматизированная загрузка в систему партнёра

Новые системные компоненты:

- Файловый шлюз SFTP с контролем доступа
- Микросервис кэширования ставок (Java Spring Boot)
- Мониторинговая панель для отслеживания актуальности данных

#### **Процесс синхронизации данных**

Внутренний колл-центр:

1. АБС публикует изменения через REST API
2. Система колл-центра получает обновления
3. Данные сохраняются в локальную PostgreSQL
4. Отображаются в интерфейсе оператора

Партнёрский колл-центр:

1. АБС генерирует XLS-файл по расписанию
2. Файловый шлюз проверяет целостность данных
3. Осуществляется передача по SFTP
4. Система партнёра импортирует данные
