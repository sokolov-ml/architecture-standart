### <a name="_qmphm5d6rvi3">**Решение**</a>

1. **Интерфейсы для клиентов:**

   - **Сайт** (PHP + React.js):
     - Показ списка депозитов
     - Приём заявок от новых клиентов (ФИО + телефон)
     - Шифрование данных через TLS
   - **Интернет-банк** (ASP.NET MVC + MS SQL):
     - Персонализированные ставки
     - Подача заявок с SMS-подтверждением
     - Кеширование ставок для ускорения работы

2. **Бэкенд-системы:**
   - **Колл-центр** (Java Spring Boot + PostgreSQL):
     - Обработка заявок с сайта
     - Возможность ручного согласования условий
   - **АБС** (Delphi + Oracle):
     - Учёт депозитов и ставок
     - Интеграция через XLS-файлы (вместо прямого API)
   - **СМС-шлюз**:
     - Отправка уведомлений через существующего телеком-оператора

### <a name="_bjrr7veeh80c">**Альтернативы**</a>

### **1. Прямая интеграция с АБС через API**

| **Критерий**        | **Описание**                                                      |
| ------------------- | ----------------------------------------------------------------- |
| **Преимущества**    | - Мгновенная синхронизация данных<br>- Уменьшение ручного труда   |
| **Недостатки**      | - Высокий риск перегрузки АБС<br>- Требует доработки ядра системы |
| **Почему отказали** | Ограниченная производительность Oracle и перегруженность АБС      |

#### **2. Внедрение Apache Kafka**

| **Критерий**        | **Описание**                                                                |
| ------------------- | --------------------------------------------------------------------------- |
| **Преимущества**    | - Асинхронная обработка заявок<br>- Масштабируемость                        |
| **Недостатки**      | - Несовместимость с текущим интернет-банком<br>- Требует перепроектирования |
| **Почему отказали** | Высокая стоимость и сроки реализации для MVP                                |

#### **3. Новый модуль управления ставками**

| **Критерий**        | **Описание**                                                         |
| ------------------- | -------------------------------------------------------------------- |
| **Преимущества**    | - Централизованное управление ставками<br>- Автоматизация процессов  |
| **Недостатки**      | - Срок разработки 6+ месяцев<br>- Необходимость обучения сотрудников |
