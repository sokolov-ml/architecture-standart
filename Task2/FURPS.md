| Код    | Требования                                                                      | Комментарий                                  |
| ------ | ------------------------------------------------------------------------------- | -------------------------------------------- |
| **F**  | **Функциональные (Functionality)**                                              |                                              |
| F1     | Подача заявки на депозит через сайт (ФИО + телефон)                             | Для новых клиентов                           |
| F2     | Подача заявки на депозит через интернет-банк (счёт + сумма + SMS-подтверждение) | Для существующих клиентов                    |
| F3     | Отображение общих и персонализированных ставок                                  | В интернет-банке                             |
| F4     | Шифрование передаваемых данных (TLS/HTTPS)                                      | Для защиты чувствительной информации         |
| F5     | Интеграция с колл-центром для обработки заявок                                  | Менеджер может предложить особые условия     |
| F6     | Подтверждение заявки бэк-офисом в АБС                                           | Ручная обработка на MVP                      |
| F7     | SMS-уведомления клиенту (подтверждение ставки, открытие депозита)               | Использование существующего SMS-модуля       |
| F8     | Хранение и управление ставками (перенос с XLS в АБС или в отдельный сервис)     | Для согласования ставок                      |
| **U**  | **Удобство использования (Usability)**                                          |                                              |
| U1     | Интерфейс должен соответствовать корпоративному дизайну                         | Брендированные цвета и элементы              |
| U2     | Минимизация шагов для подачи заявки                                             | Улучшение UX                                 |
| U3     | Быстрая обратная связь (мгновенные уведомления)                                 | Уменьшение задержек                          |
| **R**  | **Надёжность (Reliability)**                                                    |                                              |
| R1     | Доступность 99.9% (24/7) для интернет-банка и сайта                             | Требуется отказоустойчивость                 |
| R2     | Резервирование в двух ЦОД                                                       | На случай аварии                             |
| R3     | Горизонтальное масштабирование интернет-банка                                   | Для распределения нагрузки                   |
| R4     | Избегать прямого взаимодействия интернет-банка с АБС                            | Чтобы не перегружать АБС                     |
| **P**  | **Производительность (Performance)**                                            |                                              |
| P1     | Время отклика < 1 сек для операций                                              | Устранить задержки при загрузке справочников |
| P2     | Оптимизация запросов к АБС                                                      | Чтобы не перегружать базу                    |
| P3     | Кеширование часто используемых данных (ставки, условия депозитов)               | Уменьшение нагрузки                          |
| **S**  | **Поддерживаемость (Supportability)**                                           |                                              |
| S1     | Использование существующих технологий (MS SQL, Oracle)                          | Минимизация новых решений                    |
| S2     | Совместимость с Kafka для асинхронной обработки                                 | Перспективное решение                        |
| S3     | Документирование архитектуры для будущего масштабирования                       | Подготовка к микросервисам                   |
| S4     | Минимизация доработок ядра (SMS-модуль)                                         | Использовать текущую реализацию              |
| **+R** | **+ Ограничения (Restrictions)**                                                |                                              |
| +R1    | АБС не поддерживает горизонтальное масштабирование                              | Только вертикальное                          |
| +R2    | Текущая версия интернет-банка несовместима с Kafka                              | Возможен переход позже                       |
| +R3    | Ограниченные ресурсы АБС (перегружена)                                          | Избегать прямых запросов                     |
| +R4    | Использование имеющихся языков программирования                                 | Для упрощения поддержки                      |
